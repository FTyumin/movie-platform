# Redesign Status (Cinebold)

Tracks which pages have been migrated to the current **Cinebold** visual system
(near-black + projector-amber, `Jost`/`font-display`, pill radii — see
`resources/css/app.css`) versus which still use the older Marquee/Breeze-era
styling (`font-condensed`, gray/indigo Tailwind defaults).

Generated by inspecting `routes/web.php` + `routes/auth.php` against
`resources/views/**/*.blade.php` for Cinebold markers
(`font-display`, `cb-bloom`/`cb-iris`, `rounded-selector`) vs legacy markers
(`font-condensed`, `text-gray-*`, `indigo-*`, `bulb`).

## Notes

- The `feat: login/register page design` commit (`28583ac`) only touched
  `auth/login.blade.php` — despite the message, `auth/register.blade.php`
  still uses the old styling. Per prior design notes, it should reuse
  login's two-floating-card layout with the tab switcher set to "Create
  account" when tackled.
- `layouts/app.blade.php` carries no strong marker either way (it's mostly
  structural) but wraps every authenticated page, so its child pages
  determine whether a page reads as redesigned.
- `movies/list.blade.php` (shared by favorites/seen/watchlist) has no strong
  legacy or Cinebold markers but predates the redesign and should be
  reviewed alongside `dashboard.blade.php`.
